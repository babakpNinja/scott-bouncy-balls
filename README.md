# Scott — Bouncy Ball Hello World

A single-page physics toy: bouncy balls that each render the word **Scott** in a
different typeface (18 in total, Google Fonts + system stacks).

- Click the background to drop a ball
- Drag and fling any ball
- Toggle gravity, fire a confetti burst, or reset the scene

Deployed on Railway from a Dockerfile (`python -m http.server` on `$PORT`).
